## VHB 테이프는 다시 생각해보세요

제가 앞서 권했던 [3M VHB 5140 (18mm × 4m)](https://www.devicemart.co.kr/goods/view?no=12749838)은
**17,600원(VAT 포함)**으로, 이 목록에서 단일 최고가 부품입니다.

노드 하나 붙이는 데 필요한 건 손바닥만 한 넓이인데 4미터를 사는 건 과합니다.
**일반 강력 양면테이프로 시작하시고**, 진동 전달이 부족하다 싶으면 그때 VHB로
바꾸셔도 늦지 않습니다. 다이소 같은 데서 2~3천 원이면 구합니다.

성능 차이는 분명히 있습니다. VHB는 아크릴 폼이라 진동을 잘 전달하고 오래 붙어 있어요.
다만 이 단계에서 1만 원 이상을 쓸 필요는 없다고 봅니다.

## 주문 전 확인 사항

**배터리 커넥터는 신경 안 쓰셔도 됩니다.** 납땜 버전에서는 어차피 커넥터를 잘라내고
XIAO의 BAT 패드에 직접 붙이니까, Molex든 JST든 상관없습니다.

**ADXL345 헤더 상태**는 상세페이지에 명시가 없습니다. 미납땜으로 와도 어차피
납땜하실 거라 문제없지만, 핀헤더 여유분을 하나 담아두시는 이유가 이겁니다.

**XIAO는 2개** 필요합니다. 하나는 바닥 센서 노드, 하나는 RDK X3에 꽂는 수신기예요.
수신기 쪽은 납땜 없이 USB만 꽂으면 됩니다.

## 배선 (재확인)

| ADXL345 | XIAO ESP32C3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SDA | D4 (GPIO6) |
| SCL | D5 (GPIO7) |
| INT1 | D1 (GPIO3) |
| CS | 3V3 |
| SDO | GND |

배터리 → XIAO 뒷면 `BAT+`(빨강) / `BAT−`(검정) 패드.
**극성 반대면 보드가 즉시 죽습니다.** 납땜 전 멀티미터로 확인하세요.

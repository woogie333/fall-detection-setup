# 무선 진동센서 부품 리스트 — 재점검

점검일: 2026-08-17

앞서 드린 목록을 다시 훑으면서 **누락 3건, 오류 1건**을 찾았습니다.
"중간에 뭐가 더 필요한 일이 없도록" 하는 게 목적이었으니 이번엔 조립 과정을
처음부터 끝까지 시뮬레이션하며 점검했습니다.

---

## 새로 발견한 누락

### 1. USB-A ↔ USB-C 케이블 (수신기용)

수신기 XIAO를 RDK X3에 꽂아야 하는데, **RDK X3의 포트는 USB-A**이고
**XIAO는 USB-C**입니다. 따라서 필요한 건 **A to C** 케이블입니다.

맥 쓰시니까 집에 있는 케이블이 C to C일 가능성이 높은데, 그건 RDK X3에 안 꽂힙니다.
이거 하나 때문에 조립이 하루 밀릴 수 있어서 앞에 뒀습니다.

노드용(충전·프로그래밍)은 맥에 꽂을 거라 C to C여도 됩니다.
정리하면 **A to C 1개 + C to C 또는 A to C 1개**입니다.

### 2. 납땜 도구 — 이게 사실상 전제 조건입니다

납땜이 필요한 곳이 생각보다 많습니다.

| 대상 | 내용 |
|---|---|
| XIAO 핀헤더 | 14핀 × 2개 보드 = 28군데 |
| ADXL345(GY-291) 핀헤더 | 대개 미납땜 상태로 옵니다 |
| 배터리 리드 → BAT 패드 | 2군데. 작고 까다로움 |

**GY-291도 헤더가 안 붙어 있다**는 걸 앞서 짚지 않았습니다.
즉 납땜 없이는 이 프로젝트가 시작이 안 됩니다.

필요한 것: 납땜인두(30~60W 또는 온도조절형), 납, 인두 거치대.
학교 실습실을 쓰실 수 있으면 굳이 안 사셔도 됩니다.

### 3. 절연·마감 재료

배터리 리드를 BAT 패드에 납땜한 뒤 그대로 두면 **합선 위험**이 있습니다.
리튬 배터리 합선은 발화로 이어질 수 있어 그냥 넘어갈 문제가 아닙니다.

- 열수축 튜브 (소형, 2~3mm) 또는 캡톤 테이프
- 절연 테이프

## 정정 — 배터리 치수가 다릅니다

3D 모델링 문서에 배터리를 **50 × 34 × 5 mm**로 적었는데, 디바이스마트가 취급하는
TW102050은 **20 × 50 × 10 mm**입니다. 폭은 좁고 **두께는 두 배**입니다.

케이스 설계에 직접 영향이 갑니다.

| 항목 | 이전 계산 | 수정 |
|---|---|---|
| 배터리 두께 | 5 mm | **10 mm** |
| 노드 전체 높이 | 12~15 mm | **18~20 mm** |
| 배터리 바닥 면적 | 50 × 34 | **50 × 20** (더 좁음) |

바닥에 두는 물건이 20mm면 발에 걸릴 수 있습니다. 두 가지 방향이 있습니다.

**더 납작한 셀을 찾기** — 503450 규격(50×34×5mm) 같은 5~6mm 두께 셀을 구하면
원래 설계대로 갑니다. 디바이스마트 외 다른 곳도 찾아보시면 나옵니다.

**두께를 받아들이고 모서리를 경사지게** — 20mm여도 가장자리를 완만하게 깎으면
발에 덜 걸립니다. 벽 모서리나 가구 밑에 붙이면 실용상 문제없고요.

모델링 시작 전에 **실제 살 배터리를 먼저 확정**하시는 게 좋겠습니다.

## 조립 순서 시뮬레이션

실제로 손을 움직이는 순서대로 나열해봤습니다. 여기서 막히는 지점이 없으면
부품이 빠짐없다는 뜻입니다.

1. XIAO 2개에 핀헤더 납땜 → **인두 필요**
2. ADXL345에 핀헤더 납땜 → **인두 필요**
3. 맥에 XIAO 연결(USB-C), Arduino IDE 또는 ESP-IDF로 블링크 업로드 → **C 케이블**
4. 점퍼로 ADXL345 ↔ XIAO 연결, I2C 읽기 확인 → **점퍼 와이어**
5. 두 번째 XIAO를 RDK X3에 연결 → **A to C 케이블** ← 여기서 자주 막힘
6. ESP-NOW 송수신 테스트
7. RDK X3에서 `/dev/ttyACM0` 읽기 확인
8. 딥슬립 + INT1 웨이크업 구현
9. 배터리 커넥터 절단 → BAT 패드 납땜 → **열수축 튜브로 절연**
10. 소비전류 측정 → **멀티미터**
11. 케이스에 조립, 바닥 고정 → **VHB 테이프**

**5번과 9번이 새로 추가된 의존성**입니다. 이전 목록으로는 여기서 멈췄을 겁니다.

## 배선 (변경 없음)

| ADXL345 | XIAO ESP32C3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SDA | D4 (GPIO6) |
| SCL | D5 (GPIO7) |
| INT1 | D1 (GPIO3) |
| CS | 3V3 |
| SDO | GND |

`D1(GPIO3)`은 딥슬립에서 깨울 수 있는 핀이어야 합니다. ESP32-C3는 GPIO0~5가
딥슬립 웨이크업을 지원하므로 GPIO3은 적합합니다.

배터리: XIAO 뒷면 `BAT+`(빨강) / `BAT−`(검정). **극성 반대면 보드가 즉시 죽습니다.**

## 아직 열려 있는 것

**배터리 최종 선택** — 두께가 케이스 설계를 좌우하므로 이것부터 정하세요.
5~6mm 납작한 셀을 찾으면 노드가 훨씬 날렵해집니다.

**납땜 가능 여부** — 이게 안 되면 부품 구성을 다시 짜야 합니다.
헤더가 미리 납땜된 보드를 찾거나, 배터리 대신 USB 상시 전원으로 가는 등
설계 자체가 바뀝니다.

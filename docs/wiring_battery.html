진동 노드 — 배터리 및 잔량 측정 배선

XIAO ESP32C3 · ADXL345 · 3.7V 리튬폴리머

극성을 반대로 물리면 XIAO 가 즉시 죽습니다. 납땜 전에 멀티미터 DC 전압 모드로 배터리 두 선을 재서 어느 쪽이 +인지 확인하세요. 빨간 선이 항상 +라고 믿으면 안 됩니다.

연결 요약

출발도착비고
배터리 +XIAO BAT+뒷면 패드
배터리 −XIAO BAT−뒷면 패드
BAT+R1 위쪽잔량 측정용 분압
(선택 사항)
R1 아래 = R2 위XIAO A0 (D0)
R2 아래쪽GND

저항 고르기

정확한 값보다 두 저항이 같은 값인 게 중요합니다. 같으면 전압이 정확히 절반이 되고, 펌웨어의 BATT_DIVIDER 를 2.0 으로 두면 됩니다.

저항쌍상시 소모비고
100kΩ + 100kΩ약 18 µA쓸 수 있지만 배터리를 가장 많이 먹음
200kΩ + 200kΩ약 9 µASeeed 권장. 무난함
470kΩ + 470kΩ약 4 µA좋음
1MΩ + 1MΩ약 1.8 µA상한. 더 키우면 ADC 값이 부정확해짐

값이 서로 다른 저항밖에 없다면 BATT_DIVIDER = (R1 + R2) / R2 로 바꾸면 됩니다. 예를 들어 R1=100k, R2=200k 면 1.5.

배선 후 할 일

  1. 펌웨어에서 #define HAVE_BATT_SENSE 1 로 변경
  2. 업로드 후 시리얼에 [배터리] 3920mV (60%) 가 찍히는지 확인
  3. 대시보드 진동센서 카드에 잔량이 뜨는지 확인
값이 실제 배터리 전압과 다르면 멀티미터로 배터리를 직접 재서 비교하세요. 차이가 일정한 비율이면 BATT_DIVIDER 를 그 비율만큼 조정하면 됩니다. ESP32 의 ADC 는 개체차가 있어 몇 % 오차는 정상입니다.
분압 저항은 배터리를 상시 소모합니다. 딥슬립 전류(약 85 µA)에 더해지므로, 수명을 최대한 늘리려면 큰 저항을 쓰거나 이 회로를 아예 넣지 마세요. 잔량 표시는 편의 기능이지 필수가 아닙니다.

먼저 STEP 파일을 받으세요. GroupGets 의 PureThermal 3 제품 페이지에서 STEP 파일을 제공합니다. CAD 에 그대로 불러오면 홀 위치·렌즈 중심·커넥터 위치가 전부 정확하게 들어오므로, 위 표의 PureThermal 관련 항목은 재지 않아도 됩니다. D-Robotics 자료 페이지에도 RDK X3 STEP 이 있는지 확인해 보세요.

STEP 이 없는 부품은 직접 재야 합니다. 렌즈 관련 값이 가장 중요합니다. 개구부가 어긋나면 화각이 잘리고, 이건 조립 후에야 발견됩니다. 렌즈 중심은 보드를 자 위에 올려놓고 양쪽 모서리에서 재면 됩니다.

5. 설계 순서 제안

  1. 0장 실측표를 채운다 — 이게 안 되면 나머지가 다 추정치가 됩니다
  2. 부품 더미(직육면체)만 배치해 간섭을 확인한다
  3. 테스트 조각으로 공차를 잡는다
  4. 노드부터 출력한다 — 작고 빨라서 공차·조립 감각을 먼저 얻습니다
  5. 노드가 맞으면 메인 유닛을 출력한다

메인 유닛을 먼저 뽑고 싶은 유혹이 있지만, 크고 오래 걸려서 틀렸을 때 손해가 큽니다. 노드로 프린터의 버릇을 파악한 뒤 큰 걸 뽑는 게 결과적으로 빠릅니다.

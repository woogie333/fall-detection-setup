## 집계

```
재현율 = 잡은 낙상 / 전체 낙상 40회 = ____%
오탐   = 울린 일상동작 / 전체 일상 50회 = ____%
```

**낙상 감지에서는 놓치는 쪽이 훨씬 위험합니다.** 오탐이 조금 늘더라도
재현율을 우선하세요. 다만 오탐이 너무 잦으면 사용자가 알림을 꺼버리므로
결국 같은 결과가 됩니다 — 균형점을 찾아야 합니다.

**목표치 예시**: 재현율 90% 이상, 오탐 10% 이하.
이건 절대 기준이 아니라 출발점입니다. 실제로 재보고 조정하세요.

## 조정

| 증상 | 대응 |
|---|---|
| 낙상을 놓친다 | `--thr` 낮춤 (0.35 → 0.30) |
| 오탐이 많다 | `--thr` 올림, 또는 `--fusion-mode strict` |
| 눕기를 낙상으로 본다 | `--fall-min-hold` 늘림 (5 → 7) |
| 알람이 늦다 | `--fall-min-hold` 줄임 |
| 진동이 낙상에서 안 잡힌다 | `--escalate-g` 를 실측 g 의 절반으로 |

**한 번에 하나만 바꾸세요.** 두 개를 동시에 바꾸면 무엇이 효과가 있었는지
알 수 없습니다. 바꿀 때마다 최소 10회는 다시 재야 의미가 있습니다.

## 측정할 때 지킬 것

**안전이 먼저입니다.** 매트리스나 두꺼운 이불 위에서 하세요. 40회를 넘어지면
멀쩡한 사람도 다칩니다. 혼자 하지 마시고요.

**같은 방식으로 반복하세요.** 매번 다르게 넘어지면 측정이 아니라 관찰입니다.
동작을 정해놓고 그대로 반복해야 숫자가 의미를 가집니다.

**실패한 회차는 지우지 마세요.** 안 잡힌 경우가 가장 중요한 데이터입니다.
어떤 상황에서 놓쳤는지 비고에 적어두면 원인을 찾을 수 있습니다.

**중간에 설정을 바꾸지 마세요.** 바꿨으면 그 시점부터 다시 세야 합니다.
